 Velvora - Luxury Home Decor Ecommerce

A modern Luxury Home Decor Ecommerce website built with **React.js**, **Vite**, **Tailwind CSS**, **Context API**, **REST API**, and **JSON Server**.

This project was developed as a software-house style React Ecommerce application with complete frontend, backend integration, user authentication, wishlist management, order management, and online deployment.
